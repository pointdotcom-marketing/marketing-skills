# Illustration Reference Index

Use this index to distinguish inspection-only visual references from reusable production artwork.

## Current draft status

The seasonal brief refers to attached Point illustrations, existing paid-social ads, and a font screenshot. Only the textual brief was available when this draft structure was created, so no visual reference files have been bundled yet.

Do not claim a close match to the referenced illustration library until the actual source images have been added and inspected.

## Add each visual reference with this record

| Field | Required information |
| --- | --- |
| Filename | Descriptive stable filename, not `image1.png` |
| Source | Original file, URL, Drive location, or campaign folder |
| Owner | Point, licensed third party, or unknown |
| Status | Approved for reuse, reference only, unverified, or generated draft |
| Demonstrates | Shape language, texture, palette, layout, typography, or another specific trait |
| Restrictions | Cropping, modification, attribution, campaign-only use, or other limits |
| Reviewed | Reviewer and date when known |

## Recommended filename patterns

- `illustration-home-landscape-01.png`
- `illustration-people-home-01.png`
- `paid-social-layout-portrait-01.png`
- `typography-century-circular-01.png`

Store inspection-only images beside this index under `references/visual-references/`. Store approved reusable illustration source files under `assets/approved-illustrations/` and keep their original filenames when provided by Point.

Inspect actual alpha transparency to distinguish viewer backgrounds from artwork; black pixels are not automatically viewer chrome.
