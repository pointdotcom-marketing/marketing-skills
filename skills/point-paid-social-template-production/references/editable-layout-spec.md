# Editable Social Layout Specification

Use this structure for editable paid-social templates unless the current campaign brief provides an approved exception.

## Canvas and safe area

- Use the exact requested dimensions and aspect ratio.
- For a standard portrait feed asset, use `1080 × 1350 px` or an equivalent `4:5` PowerPoint slide ratio.
- Define a consistent safe area before placing content. Keep all copy, logos, icons, and legal text inside it.
- Preserve generous outer margins and intentional space between the headline, subheader, illustration, benefits, and footer.
- Do not stretch, distort, or awkwardly crop the illustration.

## Required object structure

Keep these as separate selectable objects or groups:

1. Point logo
2. Headline text
3. Subheader text
4. Main illustration
5. Benefit-row container
6. Each benefit icon or checkmark
7. Each benefit text block
8. Legal footer text
9. Optional background shapes or texture overlays

Do not bake copy into the illustration or use a flattened slide image as the template background.

Use meaningful object names when the authoring format supports them, such as `logo`, `headline`, `subheader`, `illustration`, `benefit-1-icon`, `benefit-1-copy`, and `legal-footer`.

## Default hierarchy

- Place the Point logo at the top with approved clear space.
- Keep the headline large, concise, and centered unless the campaign specifies another alignment.
- Give the subheader comfortable separation from the headline.
- Make the illustration the dominant visual area.
- Place benefits in a consistent row near the bottom.
- Reserve a dedicated footer zone so legal text is not overlaid on complex artwork.
- Prevent a single-word final line in the headline.

## Typography

- Use the approved Point font files when available.
- Keep text editable even when a fallback is required.
- Record every font fallback in the style guide.
- Apply campaign-specific line spacing only after resolving it against the current brand rules.
- Adjust type size, width, or deliberate line breaks before compressing tracking or allowing a widow.

## Illustration placement

- Place the main illustration as its own image or vector object.
- Preserve transparency around standalone illustration assets.
- Keep illustration boundaries clear of essential copy and the legal footer.
- Keep decorative shapes subordinate to the message and main scene.

## Delivery style guide

List:

- font family and weight by text role
- any font substitution
- color names and exact values
- line spacing and key spacing decisions
- canvas dimensions and safe-area approach
- illustration source or generated status
- unresolved approval or import limitations
